## 🧠 About Me

I'm a **Full Stack Developer** and 2025 Computer Science Engineering graduate from VTU, Bengaluru, focused on building production-grade web applications with modern JavaScript frameworks and AI integration.

My core strength is shipping **end-to-end products** — from database schema design to polished, responsive UI — using the Next.js / React ecosystem alongside serverless Postgres (Neon), Supabase, and MongoDB. I've integrated **Google Gemini AI** into a live, deployed product (AI Interview Mocker), handling real-world engineering challenges like SSR hydration issues, API model switching, and authentication flows with Clerk.

I also carry a **data science foundation** from an internship where I worked with Python, pandas, and scikit-learn on large tabular datasets — giving me a practical, cross-disciplinary view of building AI-assisted products, not just consuming APIs.

**🎯 Open To:** Entry-level Full Stack / Frontend Developer roles · Freelance web development · Collaborative open-source projects
